# GROWTH THEME LIBRARY

A running list of the page themes available to members, kept so the library
grows deliberately and a future build reuses a theme instead of making a
near-duplicate of one.

**Add a row every time a theme is added.** Before building a new one, read
this list and check whether an existing theme already does the job.

The eleven original themes came from the template diversity pass. Anything
added since is listed below it with the build that produced it and, more
importantly, what it does that none of the others do.

## Added since

### Two Sides of the Business (`dual-offer`)

- **Added:** 2 August 2026, first build through the Growth Build Kit
- **Built for:** WeCare Products, who organises business networking events
  and separately sells wellness products
- **Hero:** `duo`
- **Anchor:** editorial serif, soft-shadow cards, pill eyebrows, airy
  spacing. No other anchor uses that combination; Storyteller is the other
  serif theme and goes the opposite way with hard editorial rules and no
  shadow, so the two do not read as the same page.

**What it does that none of the others do.** Every other hero in the library
ends in a single call to action, which is right for a business that does one
thing and wrong for one that does two. This hero ends in two doors of equal
weight, each with a line saying what is behind it. The second door is the
shop and it appears only when the member actually has products, so a member
who picks this template without a shop still gets a finished page rather than
an empty box.

It also puts a tappable phone number and WhatsApp link in the hero. That is
a deliberate departure: Growth normally holds every number back until the
lead form is submitted, and the Growth Build Kit asks for a contact action
visible without scrolling. This is the only theme where the Build Kit wins,
and it changes nothing for members on any other template.

**Reuse it for:** a salon that sells product, a coach who runs workshops and
sells courses, a farm with a shop and a venue, a practitioner who consults
and retails. Anywhere the business genuinely has two front doors.

### Fieldwork (`fieldwork`)

- **Added:** 3 August 2026, second build through the Growth Build Kit
- **Built for:** Jetting Worx, high-pressure cleaning and drain jetting in
  Edenvale, working across Gauteng
- **Hero:** `jobcard`
- **Anchor:** display-condensed headings, stamped `steel-plate` cards (hard
  offset shadow, not blur), a new `stencil-tag` eyebrow (thick accent rule
  hard against mono caps), standard spacing on a light surface.

**What it does that none of the others do.** This is the first anchor with a
structural override on five sections, not just services, which is a direct
answer to the WeCare feedback that below the hero every template still read
the same. Services render as a full-width numbered ledger (`work-index`),
about as a stamped pull-statement behind a heavy rule (`statement`), how-it-
works as one continuous job line with mono markers (`jobline`), the gallery
as an evidence board with REF labels and one documentary-scale frame
(`evidence-board`), and location as the page's single dark dispatch-board
band (`coverage-panel`). The hero reads like the top of a job sheet: stencil
name, blunt uppercase headline, and three ways to start the job (form, call,
WhatsApp) plus a dispatch strip of real record fields only (city, phone,
email; empty fields drop their cell).

Like `dual-offer`, it puts tappable contact in the hero, the Build Kit rule
for done-for-you builds; nothing changes for members on other templates.

**Reuse it for:** any trade that works at the customer's premises on an
urgent, physical problem. Plumbing, pest control, electrical, rubble removal,
paving, roofing, tree felling. The visitor has the problem right now and is
holding a phone; the page behaves accordingly.
