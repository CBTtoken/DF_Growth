# Sprints

Dewald's sprint run handoffs live here, one file per sprint, added as each
is ready. A Claude session picks up a handoff from this folder, works it,
and ticks it off.

How a sprint gets worked, so every session does it the same way:

1. Read `CLAUDE.md` section 0.0 and `ESTATE.md` first, as always.
2. Read the handoff fully before touching anything. Its acceptance
   criteria are the definition of done, alongside the standing house
   rules: verify live with strings a page actually renders, delete test
   data before reporting done, sitemap and metadata on any new public
   surface, Turnstile on any anonymous form.
3. When a sprint is complete, mark it clearly at the top of the handoff
   file (done, date, what shipped) rather than deleting it, so the folder
   stays a record of what was run.
