# Before you start

**Confirm you are in the right repository.** `ESTATE.md` at the root of this
repo is the only cross-repository map: which folder holds which product, what
is live where, and which folders look like projects but hold no code. The
folder named `Claude Projects` is the FortisLex application, not a parent
folder for all work, and that has caught a session out before.

Then read `CLAUDE.md` section 0.0. Several sessions run against this
repository at once and cannot see each other, so it is not optional.

`docs/DOCUMENT_INDEX.md` says where every specification lives and which have
been superseded. When two specs disagree the newer one wins, and the live
system beats both.
